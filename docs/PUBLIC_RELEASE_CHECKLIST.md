# Public release checklist

This repository has been prepared for public release, but the following owner decisions must be made before publication.

| Decision | Current status | Owner action required |
|---|---|---|
| Repository visibility | Not published | Confirm public release. |
| Repository name | `floquet-tls-pi-edge-tls` | Confirm or rename before creation. |
| Code license | No license selected | Choose MIT, BSD-3-Clause, GPL-3.0, or another license appropriate for the project. Without a license, public visibility does not grant reuse permission. |
| Author list and affiliation | Not included | Add only verified author names and institutional affiliations. |
| Citation metadata | Placeholder only | Add a `CITATION.cff` after the manuscript title, authors, and preferred citation are final. |
| Preprint disclosure | Zenodo DOI listed in README | Confirm that the record's licence and content can be linked from the repository. |
| Data scope | Compact checkpoints included | Confirm that the checkpoints may be publicly redistributed. |

The repository deliberately excludes manuscript drafts, old manuscript figures, browser-renamed data duplicates, temporary checkpoint files, local review notes, account credentials, and environment-specific paths.
