# Gate D1 corrected route decision: proceed to a frozen N=6 transfer test

## Frozen decision, correctly implemented

Gate D1 **authorizes a separately frozen N=6 confirmation campaign**. The prospective N=4 protocol required both fixed-$\nu_0$ median raw-weight ratios to exceed 10 and the smallest sampled $\nu_\pi=1$ weight to exceed the largest sampled $\nu_\pi=0$ weight. The observed values are 239.10, 4276.67, and 7.004, respectively, so all three literal conditions pass.

The superseded v1 audit accidentally reused the factor-10 median threshold for the all-point condition. That extra threshold does not appear in the frozen protocol. Correcting the audit is therefore protocol compliance, not post hoc relaxation. The protocol, candidates, raw responses, and manifest remain unchanged.

Neither result establishes a universal $\nu_\pi$-weight law. The N=4 stratified design does not put every class on a common-period line, and its within-class weights remain heterogeneous. The correct paper language remains **finite-system, drive-class-dependent, and boundary-selective** until the N=6 transfer test is completed.

## Authorized next steps

Gate D1 authorizes only an N=6 transfer test on the same eight response-blind-selected drives, with no response-informed replacement or retuning.
